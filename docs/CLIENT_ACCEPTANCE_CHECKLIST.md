# CR Mariposa — Client Acceptance Checklist / Lista de aceptación

Use this checklist on the staging site before production approval. Record issues with the page, language, device, and a screenshot. / Use esta lista en el sitio de pruebas antes de aprobar producción. Registre cada problema con la página, idioma, dispositivo y una captura.

## Public website / Sitio público

- [ ] Desktop and mobile navigation reaches Homes, About, Property Management, and Contact in English and Spanish. / La navegación en computadora y móvil abre Propiedades, Nosotros, Administración y Contacto en inglés y español.
- [ ] The language switch keeps the visitor on the equivalent EN/ES page. / El selector de idioma mantiene al visitante en la página equivalente EN/ES.
- [ ] Home, catalogue, every property, photo gallery, About, Property Management, Contact, and the 404 page have approved copy and images. / Inicio, catálogo, cada propiedad, galería, Nosotros, Administración, Contacto y la página 404 tienen textos e imágenes aprobados.
- [ ] At 320 px and common phone widths, no content is clipped or scrolls sideways; the mobile discovery bar ends cleanly after “Explore/Explorar.” / A 320 px y anchos comunes de teléfono, nada se corta ni se desplaza lateralmente; la barra de búsqueda móvil termina correctamente después de “Explore/Explorar”.
- [ ] All WhatsApp, telephone, email, map, social, and marketplace links use approved destinations. / Todos los enlaces de WhatsApp, teléfono, correo, mapa, redes y plataformas usan destinos aprobados.
- [ ] Property facts, location descriptions, amenities, rules, cancellation terms, and sleeping arrangements are accurate. / Los datos, ubicaciones, amenidades, reglas, cancelación y distribución de camas son correctos.
- [ ] Images are sharp, correctly cropped, ordered as intended, and have meaningful alternative text. / Las imágenes son nítidas, están bien recortadas y ordenadas, y tienen texto alternativo útil.

## Inquiry and accessibility / Consultas y accesibilidad

- [ ] Submit one valid inquiry in each language and confirm the success message and Lead record. / Envíe una consulta válida en cada idioma y confirme el mensaje de éxito y el registro en Leads.
- [ ] Confirm validation messages are understandable and no reservation, availability, or payment is promised. / Confirme que los mensajes de validación sean claros y que no se prometa reserva, disponibilidad ni pago.
- [ ] Navigate each major page using only Tab, Shift+Tab, Enter, Space, and Escape; focus is always visible and follows a logical order. / Recorra cada página principal usando solo Tab, Shift+Tab, Enter, Espacio y Escape; el foco siempre es visible y sigue un orden lógico.
- [ ] Text is comfortable to read and interactive controls are easy to tap on a phone. / El texto es cómodo de leer y los controles son fáciles de tocar en un teléfono.

## CMS owner walkthrough / Recorrido del CMS con el propietario

- [ ] Complete every operation in [CMS_ADMIN_CHECKLIST.md](CMS_ADMIN_CHECKLIST.md), including create, edit, draft, publish, hide, upload, replace, reorder, and delete. / Complete cada operación de [CMS_ADMIN_CHECKLIST.md](CMS_ADMIN_CHECKLIST.md), incluyendo crear, editar, guardar borrador, publicar, ocultar, subir, reemplazar, reordenar y eliminar.
- [ ] Confirm editor access is sufficient and admin-only operations remain restricted. / Confirme que el acceso de editor sea suficiente y que las operaciones administrativas sigan restringidas.
- [ ] Test the largest owner-approved original image through the real staging upload workflow. / Pruebe la imagen original aprobada más grande mediante el flujo real de carga en staging.
