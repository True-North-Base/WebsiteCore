# CR Mariposa CMS quick start / Guía rápida del CMS

Admin URL: `https://cr-mariposa-staging.netlify.app/admin`

## English

1. Sign in with the email and temporary password provided separately. Open your account menu, choose **Account**, set a private password, sign out, and sign in again.
2. Open **Rentals → Properties**. Choose an existing home to edit or **Create New** to add one.
3. Complete the required fields under each tab. Use the language selector for every localized field and review both English and Spanish before publishing.
4. Upload images under **Content → Media** with useful English and Spanish alt text. Select the hero image, add gallery images, choose categories, and drag them into the intended order.
5. Use **Save Draft** while the listing is incomplete. A draft is not visible to guests. Choose **Publish** only after both languages, facts, and photographs are approved.
6. To remove a home from the public website, change it back to draft/unpublished. Permanent deletion is reserved for the administrator so content cannot be erased accidentally.
7. Published homes automatically appear in the property catalogue and sitemap. Contact the administrator before adding a location outside the current Santa Ana, Escazú, or Pacific-coast structure.

Password-reset emails are not enabled yet. If access is lost, contact the administrator for a new temporary password. Never send passwords in ordinary email or WhatsApp, and always sign out on a shared device.

## Español

1. Inicie sesión con el correo y la contraseña temporal enviados por separado. Abra el menú de su cuenta, seleccione **Account**, establezca una contraseña privada, cierre sesión y vuelva a ingresar.
2. Abra **Rentals → Properties**. Seleccione una propiedad existente para editarla o **Create New** para agregar una nueva.
3. Complete los campos obligatorios de cada pestaña. Use el selector de idioma para cada campo localizado y revise inglés y español antes de publicar.
4. Cargue imágenes en **Content → Media** con texto alternativo útil en inglés y español. Seleccione la imagen principal, agregue las fotos de la galería, elija sus categorías y ordénelas arrastrándolas.
5. Use **Save Draft** mientras el anuncio esté incompleto. Un borrador no es visible para los huéspedes. Seleccione **Publish** solamente cuando ambos idiomas, los datos y las fotografías estén aprobados.
6. Para retirar una propiedad del sitio público, vuelva a dejarla como borrador/no publicada. La eliminación permanente está reservada al administrador para evitar borrar contenido por accidente.
7. Las propiedades publicadas aparecen automáticamente en el catálogo y el sitemap. Consulte al administrador antes de agregar una ubicación fuera de la estructura actual de Santa Ana, Escazú o la costa del Pacífico.

Los correos de recuperación de contraseña todavía no están habilitados. Si pierde el acceso, solicite una nueva contraseña temporal al administrador. Nunca envíe contraseñas por correo normal o WhatsApp y cierre siempre la sesión en equipos compartidos.
